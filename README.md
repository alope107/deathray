# The Mac Deathray

A simple proof of concept of how a malicious WebGPU shader can lead to a kernel panic on MacOS. This was disclosed to Apple on 7/27/26 and Apple classified it as not a security bug.

See the [blog post](https://auberon.xyz/blog/posts/deathray/) for a description of how it works and a discussion of the significance or lack thereof of issues like this.
